# Architecture Overview

## Backend Structure
- `agents/` - Specialized AI agents
- `core/` - Core orchestration logic
- `llm/` - LLM integration
- `api/` - API endpoints (FastAPI)
- `models/` - Data models
- `cache/` - Caching layer

## Frontend Structure
- `app/` - Next.js pages
- `components/` - React components
- `lib/` - Utilities
- `hooks/` - Custom hooks
- `stores/` - State management
