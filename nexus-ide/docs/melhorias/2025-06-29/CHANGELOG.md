# Changelog — NEXUS IDE Recovery

## [2025-06-29] Deep Improvement Sprint

### Security (CRITICAL)

- **Fixed broken authentication** — `pwd_context` was never defined, causing runtime `NameError`. Now uses `bcrypt` directly with proper hashing/verification.
- **Removed hardcoded JWT secret** — `SECRET_KEY` no longer falls back to `"dev-secret-change-in-production"`. Startup fails gracefully if `NEXUS_SECRET_KEY` env var is missing or < 32 chars.
- **Added auth middleware** — Critical routes now protected with `Depends(get_current_user)`:
  - `/api/chat`, `/api/files/*`, `/api/agents/*`, `/api/tasks/*`, `/api/knowledge/*`, `/api/projects/*` (except GET list), `/api/omega/*`
- **Fixed CORS wildcard** — Removed dangerous `NEXUS_CORS_ALL=true` option. CORS now restricted to explicit origins only.
- **Fixed path traversal via symlinks** — `_validate_path()` now checks both `resolve()` and `realpath()` against the project root.
- **Upgraded vulnerable dependencies** — `python-jose` 3.3.0 → 3.4.0 (CVE-2024-33663, CVE-2024-33664).
- **Added rate limiting** — SlowAPI middleware with default 30/minute limit.

### Performance (HIGH)

- **Migrated SQLite to aiosqlite** — Synchronous `sqlite3.connect()` was blocking the FastAPI event loop. Now fully async with persistent connection pool.
- **Wrapped sync file I/O in async** — `read_file()`, `write_file()`, `list_dir()` now use `asyncio.to_thread()` to avoid event loop blocking.
- **Fixed broken routing cache** — `@lru_cache` on async function was caching coroutine objects instead of results. Replaced with proper TTL cache (5 min, max 1000 entries).

### Features (MEDIUM)

- **RAG semantic code search** — Replaced stub `embeddings.py` with real implementation using `sqlite-vec` + Ollama `nomic-embed-text`. Supports `semantic`, `regex`, and `hybrid` search modes.
- **Auto test generation endpoint** — `/api/tests/generate` creates pytest stubs from source code, with LLM fallback when Ollama is available.
- **Terminal with xterm.js** — Functional terminal with NEXUS dark theme and basic commands.
- **Monaco inline AI actions** — Right-click context menu: Explain, Refactor, Generate Tests, Fix.
- **Chat routing indicator** — Shows active agent and confidence during streaming.
- **Project persistence** — Zustand store syncs with SQLite backend; survives page reload.

### DevOps / Docker (HIGH)

- **Fixed hardcoded Ollama hosts** — Replaced all `localhost:11434` with `settings.ollama_host` (env-driven). Stack now works correctly in Docker.
- **Added `.dockerignore`** — Excludes `node_modules`, `.venv`, `__pycache__`, etc.
- **Added healthchecks** — Ollama, backend, and Redis services now have Docker healthchecks.
- **Fixed Prometheus scraping** — Added `/metrics` endpoint with `prometheus_client`. Removed invalid Ollama scrape targets.

### Frontend

- **Build passes** — `npm run build` succeeds with 0 errors.
- **Project page improved** — Folder picker, toast notifications, delete confirmation, loading states.
- **API client expanded** — Added `deleteProject`, `generateTests`, `searchCode`.

### Fixed

- Circular import between `main.py` and route files (extracted `limiter.py`).
- `pyproject.toml` setuptools package discovery (was failing build).
- Auth test regressions — TestClient fixtures now properly disable auth.
